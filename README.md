🍽️ Aditya's Café – Python Ordering System

A simple Python program that allows users to order food items from a café menu.
The program calculates the total bill based on user input and handles invalid orders gracefully.

🚀 Features

Displays menu items with prices

Takes user orders (first order + optional second order)

Cleans input to avoid spelling/spacing problems

Calculates total bill

User-friendly messages

📌 Menu
Item	Price (₹)
Pasta	120
Burger	80
Pizza	200
Sandwich	60
🧠 How It Works

The menu is stored in a dictionary

User enters their first order

Program checks if the item exists

Optionally asks for a second order

Total bill is displayed
